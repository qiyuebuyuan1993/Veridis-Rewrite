# API 管理器双向接入

在词汇映射的 **AI → API 连接 → API 管理器 · 导入 / 保存** 中操作。

- **读取管理器分组**：列出标签分组和配置组，选择连接后点 **填入词汇映射**，复制 URL、Key、模型。当前连接自动保存；要更新命名 API 预设，使用原有预设保存按钮。
- 目标为 **词汇映射**（留空也视为该分组）时，点击 **对比并批量同步**，处理全部已保存 API 预设，不包含当前未保存输入。可选：
  - **仅新增**：将分组中不存在的 URL、Key、模型组合一次添加，重复组合跳过，保留原条目。
  - **词汇映射 → 管理器整组覆盖**：用全部已保存 API 替换管理器的“词汇映射”标签分组；保留其他分组。共享条目仅移除目标分组归属。相同名称和连接的条目复用原记录、备注；其他旧条目移除。
  - **管理器 → 词汇映射全部预设覆盖**：以该分组的条目替换词汇映射全部已保存 API 预设；当前连接、全局改写参数保留，同名预设原有生成参数也保留。同名条目自动加数字后缀，避免丢失连接。
- **保存到其他分组**：仍选择当前连接或某个已保存 API 预设，单条保存。不存在的分组自动创建，相同连接跳过。
- 批量覆盖前显示数量并确认；空来源可在明确确认后清空目标集合，管理器目标分组不存在则拒绝反向覆盖。遇到不完整、不支持的连接或重复标签分组名称时整批停止，不静默漏掉某一条。只有配置组名称而没有同名标签的旧目录，首次同步按配置组读取；存在同名标签后以标签归属为准。

适配 [kaelisvespera/ST-Api-Scripts](https://github.com/kaelisvespera/ST-Api-Scripts) 的 2.2.8 / catalog v2 格式，核对源码提交 `82ea902c54d8ac91dbf27cbf0668a0cf7f6407b5`。普通 SillyTavern 读取扩展设置，TauriTavern 读取扩展存储 `st-api-manager/state`。需要先启用管理器；刚启用的空目录也可接收第一条配置。旧版格式会提示更新，不自动迁移或覆盖。

管理器目前没有公开写入 API，且内部缓存目录，因此不直接修改其存储。新增和单条保存通过原生“合并导入”；用户明确选择整组覆盖时，构造保留其他分组的完整目录，通过原生“替换导入”写入，管理器还会显示一次原生覆盖确认。写入前重新核对双方快照，发现变化就关闭准备好的导入窗口并停止。已有管理器窗口未关闭时提示先关闭。保存失败保留管理器错误提示，不自动切换操作模式。未来管理器改变导入界面时可能需要更新适配。

只保存到管理器本机目录；账户同步仍由用户在管理器内操作。Key 仅进入目标连接和管理器的原有存储，不写日志、选项标签或中间下载文件。不会切换酒馆主连接或发送模型请求。

词汇映射仍使用 OpenAI 兼容协议。支持管理器 custom、openai、deepseek 来源；后两者无 URL 时使用对应默认地址。原生 Gemini 等其他协议会提示不兼容，不伪造可用连接。

验证：纯函数测试；使用对方未修改 bundle 的桌面/手机宽度隔离浏览器测试，覆盖 ST 扩展设置、模拟 TT 存储、单条保存、批量新增、双向覆盖、取消、快照保护、刷新持久化、共享条目/备注保留和存储失败。不是 Android TT 真机或真实模型验证。

运行 `node --test tests/api-manager.mjs`；浏览器测试 `node tests/api-manager-ui.mjs` 需要 `API_MANAGER_BUNDLE` 指向上述版本管理器 `index.js`，可用 `BLAI_TEST_MODULES` 和 `BLAI_TEST_CHROME` 指定 Playwright 与浏览器。对方源码不包含在词汇映射发布包中。
